WORD CLOUD GENERATOR

단어를 넣으면
워드클라우드 이미지로.

설문 응답, 학급 의견, 회의 키워드를 붙여 넣으면 많이 나온 단어를 크게 배치해 PNG 이미지로 만들 수 있습니다. 입력 내용은 브라우저 안에서만 처리됩니다.

1

단어 입력과 설정

문장이나 단어 목록을 붙여 넣고 이미지 모양을 고르세요.

쉼표, 줄바꿈, 공백으로 단어를 구분합니다. 같은 단어가 많을수록 크게 표시됩니다.
단어 분석과 이미지 생성은 서버로 전송하지 않고 현재 브라우저에서만 처리됩니다.
2

워드클라우드 이미지

결과를 확인한 뒤 PNG 이미지로 내려받으세요.

단어를 입력한 뒤 생성 버튼을 누르면 이미지가 표시됩니다.
