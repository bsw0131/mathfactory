# 수학창의공작소

수학 수업과 학교 업무를 더 쉽고 즐겁게 만드는 교사용 웹도구 모음 사이트입니다.

## 구성

- `index.html` : 메인 페이지
- `style.css` : 디자인 파일
- `app.js` : 메인 페이지 동작 파일
- `tools/student-record-textifier.html` : 생기부 텍스트화 웹앱
- `tools/student-record-textifier.js` : 생기부 텍스트화 기능 파일

## GitHub Pages 배포

1. 이 파일들을 저장소에 업로드합니다.
2. GitHub 저장소에서 `Settings → Pages`로 이동합니다.
3. Source를 `Deploy from a branch`로 설정합니다.
4. Branch는 `main`, 폴더는 `/root`로 선택합니다.
5. Save를 누르고 1~10분 기다립니다.

배포 주소 예시:

`https://bsw0131.github.io/mathfactory/`
