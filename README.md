# 수학창의공작소

수학 수업과 학교 업무에 바로 활용할 수 있는 웹도구 모음 사이트입니다.

## 포함된 웹툴

- 생기부 텍스트화: 엑셀 파일의 이름 열과 특기사항 열을 선택해 텍스트로 변환

## GitHub Pages 배포 방법

1. 이 폴더의 모든 파일과 `tools` 폴더를 저장소에 업로드합니다.
2. GitHub 저장소에서 `Settings` → `Pages`로 이동합니다.
3. `Source`를 `Deploy from a branch`로 설정합니다.
4. `Branch`는 `main`, 폴더는 `/root`로 선택합니다.
5. `Save`를 누르고 1~10분 기다립니다.

배포 주소 예시:

```text
https://bsw0131.github.io/mathfactory/
```
